# Cortes de Valor IA

Projeto gerado no Lovable e preparado para deploy no Netlify.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Netlify

O projeto já contém `netlify.toml` com:

- Build command: `npm run build`
- Publish directory: `dist/client`
